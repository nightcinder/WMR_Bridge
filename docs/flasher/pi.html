Set up WMR Bridge on a Raspberry Pi

Four steps from a blank SD card to controllers streaming over Wi-Fi.

Flashing an ESP32 board instead? Open the browser flasher.

WMR Bridge reads your Windows Mixed Reality controllers over Bluetooth and sends their data to your phone or PC over 5 GHz Wi-Fi. You need a Raspberry Pi 3 Model B+, Pi 4 or Pi 5, a microSD card, and the matching power supply.

A Pi Zero 2 W does not work: its Wi-Fi is 2.4 GHz only, the same band Bluetooth uses.

Step 1Flash Raspberry Pi OS Lite

Use Raspberry Pi Imager to write Raspberry Pi OS Lite (64-bit). The 64-bit image is required; the 32-bit one prints armv7l instead of aarch64.

  1. Choose Device: your board. For a 3B+ pick Raspberry Pi 3.
  2. Choose OS: Raspberry Pi OS (other), then Raspberry Pi OS Lite (64-bit).
  3. Choose Storage: your microSD card.
  4. Click Next, then Edit Settings: set a hostname (for example wmr-pi), a username and password, your 5 GHz Wi-Fi network and country, and enable SSH.
  5. Save the settings, write the card, put it in the Pi and power it on. Wait 1 to 2 minutes.

The Pi and your phone or PC must both use the 5 GHz band. Run iw dev wlan0 link after you log in and look for freq: 5xxx. If it shows 24xx, reconnect to your 5 GHz network first.

Step 2Install WMR Bridge

SSH into the Pi, then run this one command. It downloads the latest release package, checks it against the release checksums, installs it and starts the service. 

curl -fsSL https://github.com/nightcinder/WMR_Bridge/releases/latest/download/install.sh | sudo bash

The command needs apt-get, which stock Raspberry Pi OS has. The installer also turns off Wi-Fi power saving; reboot once (sudo reboot) so that setting takes effect.

Check the install after the reboot: 

wmr-bridge --version
systemctl is-active wmr-bridge

Or download install.sh from this page and run it on the Pi.

Step 3Pair your controllers

The bridge pairs controllers on its own. Put one controller in pairing mode. The bridge finds it, pairs it, trusts it, and connects it. You do not run bluetoothctl.

To put a controller in pairing mode:

  1. Turn on the controller. Hold the front Windows button for 2 seconds.
  2. Open the battery cover.
  3. Hold the small pairing button inside the battery compartment until the LEDs pulse slowly.

Wait for the bridge to pair it, then repeat for the other controller. Confirm both were found: 

cat /sys/class/hidraw/hidraw*/device/uevent | grep -E 'HID_NAME|HID_UNIQ'

You should see Motion controller - Left and Motion controller - Right. The bridge sees each controller as soon as it connects; you do not restart the service.

Step 4Connect a client

The bridge listens on ws://<pi-ip>:8765/wmr. Read the token on the Pi: 

sudo cat /etc/wmr-bridge/token

Paste that token into the companion app. The companion app does not discover the Pi: enter its host and port by hand. The v0.3.21 service advertises _wmr-bridge._tcp for discovery tools (--advertise-mdns), but the app still takes a manual host and port.

Read this before using it. WMR Bridge is experimental test software, not a finished product. See the security notes before you send controller data over Wi-Fi.

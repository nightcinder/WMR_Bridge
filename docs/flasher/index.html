Install WMR Bridge

Experimental firmware for the ESP32 (classic).

This installs the WMR Bridge firmware on an ESP32 board from Chrome or Edge on a desktop, over USB. ESP-IDF is not needed. The board then connects two Windows Mixed Reality motion controllers and forwards their input to the companion Android app.

ESP32-S3 and other chips without Classic Bluetooth are not supported. You need a classic ESP32 board with at least 2 MB flash.

Your browser does not support Web Serial. Use Chrome or Edge on a desktop, served over HTTPS or from localhost. The installer needs a secure context. Open this page over HTTPS or from localhost.

This page was opened as a local file, so the firmware manifest cannot be loaded. In the build output directory, run python3 -m http.server 8000 and open http://localhost:8000.

What you need

  • An ESP32 board with 2 MB flash and a USB data cable.
  • Chrome or Edge on Windows, macOS or Linux. Firefox and Safari do not support Web Serial.
  • Nothing else: no Arduino IDE, no ESP-IDF, no Python.

Steps

  1. Connect the ESP32 to the computer with the USB cable.
  2. Click Install WMR Bridge and choose the board's serial port. If you see several ports, unplug the board and plug it back in to see which one appears.
  3. Let the installer erase and flash the board. This takes about a minute. If it says "Failed to connect", hold the board's BOOT button while it retries, and make sure no serial monitor has the port open.
  4. Open a serial monitor at 115200 baud to check the boot log. You should see BLE advertising: WMR Bridge.
  5. On first boot, put both controllers into pairing mode within a minute. The bridge finds them by name and stores their addresses. Later they reconnect on their own.

Read this before using it. WMR Bridge is experimental test firmware, not a finished product. Its BLE service is unauthenticated and unencrypted, and the board ships with secure boot and flash encryption disabled. Anyone in radio range can receive the controller data. See docs/SECURITY.md.

Where this firmware comes from
